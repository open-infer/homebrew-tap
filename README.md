# open-infer tap

Homebrew tap and Scoop bucket for OpenInfer's command-line tools.

Install `oi`, the command-line on-ramp that points a coding harness (Claude
Code, Antigravity, Pi, oh-my-pi, OpenCode or Kilo) at OpenInfer and launches
it:

```sh
brew install open-infer/tap/oi
```

On Windows, add the same repository as a Scoop bucket:

```powershell
scoop bucket add openinfer https://github.com/open-infer/homebrew-tap
scoop install oi
```

## Formulae

- `oi` — configure and launch a coding harness against OpenInfer. See the
  [project repository](https://github.com/open-infer/oi).
